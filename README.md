# StyleSwift

**Digital Studio Management Platform for Independent Fashion Designers in Accra, Ghana**

StyleSwift replaces paper measurement notebooks and chaotic WhatsApp threads with a clean, AI-powered digital studio — accessible from any Android phone or tablet, with no app download required.

---

## What StyleSwift Does

**For Designers:**
- Digital Measurement Book with gender-split male and female measurement fields
- Catalogue management — upload design photos and tag each style by Occasion, Gender, Style Direction, Garment Type, and Fabric Family
- Orders tracking with status management (Pending → In Progress → Ready → Delivered)
- Finance ledger for income and expense tracking
- Analytics dashboard showing catalogue and order performance
- Shareable personalised link for client onboarding

**For Clients:**
- 5-question visual Style Discovery quiz — tap only, no typing, completes in 90 seconds
- AI-powered Reference Tag Engine matches client preferences to the designer's own catalogue
- Personalised style recommendation card
- One-tap WhatsApp share to send profile directly to the designer

---

## Technology

- Pure HTML, CSS, and JavaScript — no frameworks, no build tools
- Designer data stored in browser localStorage; catalogue is also synced to a lightweight Netlify Function + Blobs store so clients can view it from their own device — no separate server to manage
- Works on any Android mobile or tablet browser
- Single-file architecture for maximum simplicity and reliability
